# 03 — SHOT LIST + SEEDANCE 2 PROMPTS (SILENT FILM)

42 shots covering the full 5:00. Each shot = one Seedance 2 generation (4–15s).

> **This is a SILENT film** — no narrator, no spoken dialogue. The story is told purely
> through **visuals + music + sound effects**. The two pieces of "text" in the film are
> *in-world* and shown on screen: the **"UNDELIVERABLE"** stamp and the **medal engraving**.
> Every prompt below tells Seedance to generate ambient sound/foley/music mood but
> **NO dialogue and NO voiceover**.

## How to use this file
1. **Make the reference images in `04-character-style-refs.md` FIRST.**
2. For each shot, **copy the whole `PROMPT:` block** into Seedance 2 (it's fully written out —
   no placeholders to fill).
3. **Attach the reference images** listed in `REF:` so the character/world stays consistent.
4. Set **duration = LEN**, aspect ratio **16:9**, resolution **1080p**.
5. Generate 2–3 variations, keep the best, save it named exactly as the **shot ID**
   (e.g. `SH-07.mp4`).

Reference image keys (from file 04): `R-RIGGS`, `R-RIGGS-FACE`, `R-COCKPIT`, `R-SHIP`,
`R-CITY`, `R-CITY-STREET`, `R-PIM`, `R-PLANET`, `R-MEDAL`, `R-CRATER`.
