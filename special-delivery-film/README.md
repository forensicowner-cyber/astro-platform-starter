# SPECIAL DELIVERY — Production Package

A 5-minute sci-fi comedy animated short, inspired by the tone of *Johnny Express*,
designed to be **generated with Seedance 2.0** and **assembled in a free video editor**
(CapCut or DaVinci Resolve).

> **This is a SILENT film** — no narrator and no spoken dialogue. The story is told purely
> through **visuals + music + sound effects**. (The only on-screen words are *in-world*: the
> "UNDELIVERABLE" stamp and the medal engraving.)

> **Original story.** This is NOT a copy of *Johnny Express*. It shares the genre
> (oblivious-giant comedy) but uses original characters, world, and plot to keep
> your YouTube channel safe from copyright strikes.

---

## How this package works

You don't need to plan anything yourself. Just follow the files **in order**:

| File | What it is | What you do with it |
|------|------------|---------------------|
| `01-story-bible.md` | The concept, characters, world, visual style | Read once to understand the film |
| `02-script.md` | Full visual/beat script (silent) | Your master reference |
| `03-shot-list.md` | Every shot + the exact Seedance 2 prompt | Copy-paste prompts into Seedance 2 |
| `04-character-style-refs.md` | Prompts to make reference images | Make these FIRST (consistency) |

| `06-editing-guide.md` | Step-by-step assembly + checklist | Follow while editing |
| `07-youtube-publishing.md` | Title, description, thumbnail, tags | When you upload |

## The 7-phase workflow (big picture)

```
PHASE 1  Read story bible + script                         (~30 min)
PHASE 2  Generate character/style REFERENCE IMAGES         (file 04)
PHASE 3  Generate every CLIP in Seedance 2                 (file 03)
PHASE 4  Gather MUSIC + SFX (no voiceover needed)          (file 05)
PHASE 5  Edit: lay clips on timeline, add music/SFX        (file 06)
PHASE 6  Color, titles, export 1080p                       (file 06)
PHASE 7  Upload to YouTube                                 (file 07)
```

## Tools you'll need

- **Seedance 2.0** access (the video clips) — official platform or a partner like fal/WaveSpeed/DeepBrain AI STUDIOS.
- **Image generator** for reference frames — Seedance's image mode, Midjourney, or any text-to-image tool.
- **Editor** — CapCut (easiest, free) or DaVinci Resolve (free, more pro).
- **Music** — royalty-free library (YouTube Audio Library, Pixabay, Uppbeat).
- **No voiceover/mic needed** — this is a silent film (music + SFX only).

## Key facts about Seedance 2.0 (why the plan is shaped this way)

- Generates **4–15 second** clips → our shots are designed in that range.
- Outputs up to **1080p** → YouTube-ready.
- **Generates audio natively** (foley, ambient, music) → we keep the good foley/ambient and add a strong music score + SFX on top. **No narration/dialogue** (silent film).
- Accepts up to **9 reference images** → this is how we keep the character looking the same in every shot.
